# 언론부 소개 홈페이지

`index.html`을 더블클릭하면 브라우저에서 바로 열립니다. 설치할 것은 없습니다.

## 내용 바꾸기
- **로고 · 이메일 · SNS · 사진 · 아카이브 게시물** → `js/config.js` 한 파일만 수정
- **사진 파일** → `images/` 폴더에 넣고 `config.js`에 경로 입력 (`images/README.txt` 참고)
- **문구** → `index.html`에서 직접 수정
- **포인트 컬러** → `css/style.css` 맨 위 `--accent`

## 구성
| 메뉴 | 섹션 |
|---|---|
| ABOUT | 언론부 소개 · 운영 원칙 · 주요 업무(PHOTO / VIDEO / CONTENT / COMMUNICATION) |
| ACTIVITIES | 주요 활동 4가지 (매거진 레이아웃) |
| ARCHIVE | 최근 기록 (현재 예시 항목) |
| CONTACT | 문의 · 제보 안내, 연락 채널, 마무리 슬로건 |
